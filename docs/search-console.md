# Google Search Console и Bing для neatcv.cc

На сайте уже опубликованы [robots.txt](https://neatcv.cc/robots.txt) и [sitemap.xml](https://neatcv.cc/sitemap.xml). Sitemap содержит две самостоятельные страницы: главную и страницу приватности. Редактор, параметры `?ref=…` и адреса с `#` в него не входят; галерея компонентов помечена `noindex`.

Это техническая подготовка, а не подтверждение владения доменом. Код DNS выдаёт аккаунт владельца в Google или Bing. Пока код не добавлен и проверка не завершена, сайт нельзя считать зарегистрированным в этих сервисах.

## 1. Google: добавить домен и TXT-запись

1. Открой [Google Search Console](https://search.google.com/search-console), войди в свой Google-аккаунт и выбери **Добавить ресурс / Add property**.
2. В колонке **Домен / Domain** введи `neatcv.cc` — без `https://`, слеша и пути. Этот вариант охватывает протоколы и поддомены.
3. В окне подтверждения выбери TXT и скопируй **всю** выданную строку вида `google-site-verification=…`. Многоточие здесь обозначает уникальный код Google: его нельзя вставлять буквально или заменять придуманным кодом.
4. Открой [Cloudflare Dashboard](https://dash.cloudflare.com), выбери `neatcv.cc` → **DNS → Records → Add record** и заполни:

   | Поле    | Значение                                                            |
   | ------- | ------------------------------------------------------------------- |
   | Type    | `TXT`                                                               |
   | Name    | `@` (корень `neatcv.cc`)                                            |
   | Content | Полная строка `google-site-verification=…`, скопированная из Google |
   | TTL     | `Auto`                                                              |

   Сохрани новую запись. Существующие A, CNAME, MX и TXT оставь на месте. TXT не использует проксирование Cloudflare.

5. Вернись в Search Console и нажми **Подтвердить / Verify**. Если запись ещё не видна, подожди и повтори проверку. Настройка обычно короткая, но распространение DNS может занять больше времени.
6. Не удаляй запись после успеха: Google периодически проверяет владение снова.

Проверить появление записи можно командой `dig +short TXT neatcv.cc` или через [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/#TXT/neatcv.cc). Нужна строка из твоего окна подтверждения, а не чужой код.

## 2. Google: отправить sitemap

1. В подтверждённом ресурсе `neatcv.cc` открой **Индексирование → Файлы Sitemap / Indexing → Sitemaps**.
2. В **Добавить файл Sitemap** введи полный адрес **`https://neatcv.cc/sitemap.xml`** и нажми **Отправить / Submit**. Для доменного ресурса указывай полный URL.
3. Дождись статуса **Успешно / Success**. В карте две страницы; статус означает, что Google смог обработать карту, а не что обе страницы уже проиндексированы.
4. Через **Проверку URL / URL Inspection** проверь `https://neatcv.cc/`; при необходимости используй **Проверить опубликованный URL / Test live URL**, затем **Запросить индексирование / Request indexing**. Аналогично можно проверить `https://neatcv.cc/privacy.html`.

Повторно отправлять неизменённую карту каждый день не нужно. Сроки и само включение страниц в поиск определяет поисковая система.

## 3. Bing: импортировать подтверждённый сайт из Google

1. Открой [Bing Webmaster Tools](https://www.bing.com/webmasters) и войди в свой аккаунт.
2. На добавлении сайта выбери **Import from Google Search Console**. Разреши доступ к нужному Google-аккаунту и выбери только `neatcv.cc`.
3. Заверши импорт. Bing поддерживает перенос подтверждения владения и sitemap из Google.
4. Открой **Sitemaps** и проверь, что там есть `https://neatcv.cc/sitemap.xml`. Если карта не перенеслась, нажми **Submit sitemap** и введи этот полный адрес.
5. Проверь главную через **URL Inspection**. Успешный импорт и обработанная карта не гарантируют немедленную индексацию.

### Если импорт из Google не подходит

В Bing выбери ручное добавление `https://neatcv.cc/` и подтверждение DNS. **Bing выдаёт CNAME, а не Google TXT.** Скопируй имя и целевой адрес именно из окна Bing:

| Поле Cloudflare | Значение                                      |
| --------------- | --------------------------------------------- |
| Type            | `CNAME`                                       |
| Name            | Уникальное имя подтверждения, показанное Bing |
| Target          | Целевой адрес, показанный Bing                |
| Proxy status    | `DNS only` — серое облако                     |
| TTL             | `Auto`                                        |

Не заменяй основной CNAME сайта и не ставь `@`, если Bing выдал отдельное имя. После сохранения вернись в Bing, нажми **Verify**, затем отправь `https://neatcv.cc/sitemap.xml`. Сохрани запись для последующих проверок владения.

## Проверка результата

- Google показывает подтверждённый доменный ресурс `neatcv.cc` и успешно обработанный sitemap.
- Bing показывает подтверждённый сайт и обработанный sitemap с тем же URL.
- `robots.txt` и обе страницы sitemap доступны публично по HTTPS без входа.
- Статусы индексирования проверены отдельно; отсутствие страницы в выдаче сразу после настройки не равно ошибке sitemap.

Технические проверки сайта запускаются в `e2e/search.e2e.ts`. Подтверждение аккаунта и состояние индексации проверяются в кабинетах поисковых систем.
