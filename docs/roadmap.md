# Next improvements

The editor is free, private, and usable without an account. Future work should keep the path from writing to a readable PDF short.

1. **Tailor a copy to a vacancy.** Keep several named resumes locally, duplicate one for a role, and compare the job requirements with visible experience. Suggestions must never invent skills or promise a screening score.
2. **Review the actual exported text.** Show the PDF’s extracted reading order and warn about missing text, broken links, and overflow before download. Keep the current semantic text view for accessible reading.
3. **More useful section controls.** Let people reorder or omit sections, group technical skills, and add certifications. Preserve these choices in both language versions and editable backups.
4. **Import with review.** Explore extracting ordinary text PDFs into editable fields, with a clear comparison and explicit review of uncertain dates and names. Scans need a separate OCR workflow. Preserve the original file.

Delivered in this revision: a desktop workspace with independent scrolling, full-page preview and page navigation, visible section progress, English by default, profile links, the Technical template, PDF properties, and evidence-based writing guidance.
